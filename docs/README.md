# 1is4me — AI Growth Partner

Working documentation set, derived from `1is4me_Three_Doors_Blueprint_V3.pdf`
(V3 — August 2026, 12 pages).

This is a **separate project** from the kokanddryfruits / Frutaseca site that shares
this working directory. Nothing here touches that codebase.

## Status

| Layer | State |
|---|---|
| Positioning & offer architecture | Defined (from V3 blueprint) |
| Messaging & copy | Drafted — proof + pricing blocks empty |
| Site structure (content-level) | Defined |
| **Visual template / design system** | **NOT DEFINED — blocked, waiting on decision** |
| Build | Not started |

Every document here is written to be **template-agnostic**. Sections are specified by
*purpose, content slots, and conversion job* — never by layout, grid, type scale or
colour. Those decisions all live in one place: [05-template-brief.md](docs/05-template-brief.md),
which is the slot the template drops into once chosen.

## Hard rule carried over from the blueprint

> "Numbers lead in this brand system, not adjectives. Nothing invented sits on this page."

No placeholder testimonials, no invented metrics, no fake logos — not even temporarily,
not even in staging. Empty is acceptable; fabricated is not. This rule is enforced
throughout [03-messaging-copy.md](docs/03-messaging-copy.md), where every unfilled proof
slot is marked `[EMPTY — REAL DATA ONLY]` rather than filled with a sample.
